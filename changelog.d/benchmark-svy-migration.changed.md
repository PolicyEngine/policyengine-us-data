Migrated the L0 paper benchmark's GREG and IPF calibrators from R (`survey`/`surveysd`) to the in-process `svy` Python package, removing the R dependency (runner scripts, `install_r_packages.R`, and the `.npy` reader). GREG reuses the existing `GregCalibrator` and matches R `survey::grake` (classical linear `cal.linear`) to ~1e-14. IPF uses `svy` raking with household-mean and uncovered-cell padding, reproducing `surveysd::ipf` exactly on single-scope problems; each IPF run is restricted to one count family via `method_options.ipf.count_variable` (default `household_count`).
